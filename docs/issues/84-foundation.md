# Goal

Define a reboot from observed repository behavior before implementation. Players need a complete loop, not a growing collection of disconnected systems.

## Scope

Audit source, assets, toolchain, Issues and PRs; document preservation, architecture, MVP, roadmap and original-game visual reference.

## Acceptance criteria

- [x] Existing code and uncommitted changes remain intact.
- [x] Audit distinguishes fixed legacy issues from current defects.
- [x] Simulation/presentation boundary and accounting are specified.
- [x] MVP has a repeatable-day definition and explicit exclusions.
- [x] Art register includes references, size, states and priorities.
- [x] Implementation issues #85 and #86 are linked before implementation starts.
