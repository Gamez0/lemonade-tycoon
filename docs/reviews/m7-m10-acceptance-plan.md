# M7–M10 검증 및 제출 준비 계획

독립 준비 문서다. 현재 M4 실기기, M5/M6 구현, M2 시각 수용이 남아 있다.
아래 단계는 완료가 아니며 실제 실행 증거가 있을 때만 상태를 바꾼다.

## M7 알파 / #108

- M5/M6의 전체 장소와 일곱 탭을 먼저 구현한다. 각 장소 자체 미술/썸네일을
  art-assets.md에 등록하고 원작 연구 이미지 및 출처 불명 legacy 자산은 배포에서 제외한다.
- 음악 #113과 효과음은 자체 제작/권리 확인된 파일만 사용한다. master/music/effects 음량,
  mute와 focus 복귀, autoplay 실패 처리, 저장 복구를 검증한다. 음원 없이 완료로 표시하지 않는다.
- 한국어/영어 범위를 사용자와 확정한 뒤 모든 문구/숫자/키보드/도움말을 검사한다.
- 첫 실행 안내는 구매→레시피→가격→OPEN→결과→NEXT DAY 순서로 실제 버튼을 가리킨다.
  안내 재열기/건너뛰기가 장부를 바꾸지 않아야 한다.
- Windows 전용 빌드는 `npm run desktop:package:win`; 웹은 `build-nolog`로 legacy 유지.
  기본 font/라이선스가 포함되고 연구 이미지·legacy.html은 PC 빌드 검사에서 거부한다.
- 수동: 깨끗한 PC/no Node/offline, 창·DPI·Alt-Tab·정상/강제 종료를 기존 M4 체크리스트로 재검증.
  실제 관찰 뒤만 기능 동결한다.

## M8 베타 / #109

초기 목표 플레이어 5명 이상. 개인정보 없이 익명 ID, OS/DPI/빌드 SHA, 첫 3일 소요시간,
첫 OPEN 막힘, 임대/직원 비용 이해, 첫 해금 날짜, 파산/저장 문제를 기록한다.
설명 없이 플레이를 먼저 관찰하고 도움이 필요했던 지점과 수정 뒤 재관찰을 분리한다.

자동 경제 검사는 30일 × 여러 seed × 장소/가격/레시피/투자 전략을 비교한다.
매일 cash 공식, 공급 0–999, 방문자 합계, 비용 중복 없음, save round-trip을 검사한다.
잠긴 장소를 강제로 풀어 실행한 실험은 해금 진행 검증과 구분한다.
실제 장기 플레이/청취/수동 장치 검증을 자동 시뮬레이션으로 대체하지 않는다.

Windows 대표 해상도 후보 1280×720/1920×1080, DPI 100/150/200%를 실제 확인한다.
Chrome/Edge/Firefox 웹 프리뷰와 모바일 핵심 루프는 보조 회귀로 기록한다.
성능은 실제 측정한 하드웨어, 빌드, FPS/긴 프레임/메모리/30일 실행 시간을 기록한 뒤 예산을 정한다.
지원 사양은 후보를 확정 사실로 표시하지 않는다.

## M9 RC / #110

현재 구현된 도구: PC 자산 allowlist와 prototype SHA-256 파일 manifest.
`build-info.json`은 source SHA와 PR synthetic merge checkout SHA를 구분한다.
`release-manifest.json`은 자기 자신을 제외한 모든 파일/바이트/해시를 포함한다.
다운로드 뒤 개발 환경에서 `node scripts/release-manifest.cjs DIRECTORY --verify`로 검사한다.
일반 플레이어에게 Node 설치를 요구하지 않는다. 패키지는 실행에 Node가 필요 없다.

아직 할 일: 제품명/최종 버전 확정, 자체 명칭·캡슐·실제 스크린샷·영상,
전체 콘텐츠·의존 라이선스와 권리 확인, 서명/설치 방식 결정, 실제 버전 간 업데이트,
재설치/롤백, P0/P1 0개 근거와 지원 장치 결과.
현재 `0.1.0` 패키지와 unsigned prototype은 RC로 승격하지 않는다.

업데이트 전 JSON을 외부로 내보낸다. 이전 실행 파일로 새 저장을 덮어쓰지 않는다.
새 저장 버전을 이전 게임이 이해하지 못하면 종료하고 내보낸 이전 호환본만 별도 사용자 데이터에서 연다.
게임/패키지 이동이 사용자 데이터 삭제를 포함하지 않는지 실기기에서 확인한다.

## M10 Steam 제출 준비 / #111

`steam/*.vdf.example`은 편집용 템플릿이며 실행·업로드되지 않는다.
AppID/DepotID/파트너 권한/SDK/콘텐츠 권리와 M9 수용 후에만 유효한 실제 값으로 별도 복사한다.
실행 파일은 `Lemonade Tycoon.exe`, launch working directory는 패키지 루트다.
Steamworks 초기 구현은 필수가 아니다. 업적/Cloud/Overlay는 검증 전에 지원 표기하지 않는다.

검증 순서: 권리/계정 확인 → 템플릿 최신 공식 문서 대조 → 비공개 브랜치 업로드 승인
→ Steam 클라이언트 설치/offline/실행 → 실제 업데이트/저장 유지 → 스토어·빌드 심사 준비.
공개 판매/수수료/계정 생성은 이번 작업 범위에 포함하지 않는다.
AppID가 없어도 템플릿을 준비할 수 있지만 Steam 제출 준비 완료나 심사 통과로 기록하지 않는다.

공식 요구 사항은 실행 시 최신 확인:
https://partner.steamgames.com/doc/sdk/uploading
https://partner.steamgames.com/doc/store/review_process
이 문서는 공식 페이지를 이번 실행에서 다시 읽었다고 주장하지 않는다.
