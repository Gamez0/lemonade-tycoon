# Steam 등록 전 인수인계

2026-10-13에 확인한 현재 목표는 **게임과 제출 자료를 먼저 완성**하는 것이다.
Steam 계정이나 AppID가 없어도 아래 작업과 배포물 검증을 진행한다.
실제 등록·업로드·공개·판매는 사용자가 준비된 뒤 진행한다.

## 받을 자료

| 자료 | 용도 |
| --- | --- |
| Windows x64 게임 ZIP, SHA256, 전체 파일 manifest | 개발 서버 없이 실행하고 동일 배포물인지 확인 |
| 정확한 소스/CI 및 저장·업데이트 검증 기록 | 검증한 코드와 실제 전달 파일 연결 |
| 스토어 설명, 캡슐/라이브러리 이미지, 실제 게임 화면·영상 | 나중에 스토어 페이지에 입력할 자료 |
| 음악 듣기용 WAV, 크레딧과 라이선스/권리 목록 | 음원 검토 및 배포 권리 확인 |
| SteamPipe 템플릿, 실행 옵션, 설치/업데이트/롤백 절차 | 계정 준비 후 업로드와 출시 운영 |
| 콘텐츠 설문 초안과 변경 내역 | 나중에 실제 빌드와 대조해 설문/패치 설명 작성 |

자료 묶음과 실제 게임 ZIP은 별도다. Steam depot에는 게임 ZIP을 풀어 얻은
완전한 Windows 패키지만 넣는다. 연구 이미지, 개발 소스, 개인 저장 파일이나
스토어 준비 문서를 게임 depot에 넣지 않는다.

## 실행과 저장

게임 ZIP 전체를 새 폴더에 풀고 `Lemonade Tycoon.exe`를 실행한다. 실행 파일만
옮기지 않는다. UI는 영어이며 Windows x64, 마우스와 키보드가 현재 지원 범위다.
게임 내부 이름은 Willow Lane Lemonade, 실행 파일과 저장 폴더 이름은 기존 저장
호환을 위해 유지한다. 자동 저장 외에 Help / Settings의 Export save로 백업한다.

업데이트 전 저장을 내보내고 이전 패키지를 보관한다. 새 ZIP은 별도 폴더에 풀어
실행한다. 저장은 설치 폴더와 분리되어 유지된다. v7 저장은 이전 v6 게임에서
읽을 수 없으므로 롤백에는 업데이트 전 백업을 사용한다. 판매 중 강제 종료는
그날의 이미 지불한 개점 상태로 복원한다. 정상 종료 중 저장이 실패하면
Keep playing으로 재시도/백업하거나 Close without saving을 명시적으로 선택한다.
세부 경로와 절차: [운영 문서](operations.md).

## 계정 준비 후 사용할 설정

Windows x64 depot 1개, 실행 파일 `Lemonade Tycoon.exe`, 작업 폴더 `.`, Windows
플랫폼으로 구성한다. 실제 AppID와 Windows DepotID가 생기면 아래 템플릿의
자리표시자를 치환한다. 샘플 ID를 실제 게임의 ID로 쓰지 않는다.

- [app 템플릿](../../steam/app_build.template.vdf)
- [depot 템플릿](../../steam/depot_build.template.vdf)
- [Steam 준비 절차](steam-readiness.md)

검증된 패키지와 실제 ID로 `scripts/steam-prepare.cjs`를 실행하면 체크섬을
확인한 뒤 패키지 밖에 VDF를 생성한다. 기본값은 Preview=1, SetLive는 빈 값이다.
이 도구는 SteamCMD 실행이나 업로드를 수행하지 않는다. 실제 업로드 및 비공개
Steam 설치/업데이트 검증은 후속 출시 운영으로 남겨둔다.

## 별도로 확인할 사항

사람의 게임/글꼴/음악 수용, 깨끗한 Windows PC와 물리 DPI/네트워크 검증,
광고할 최소 사양, 최종 명칭/기여 콘텐츠의 배포 권리와 미디어 선택은 기록된
미확인 사항이다. 자동 테스트를 해당 승인으로 표시하지 않는다. 계정 준비는
현재 개발의 중단 사유가 아니며, 미확인 사항이 곧 출시 불가능 판정도 아니다.

나중에 실제 Steam 설치/실행/업데이트, 스토어 입력과 콘텐츠 설문, Valve의
스토어/빌드 심사를 완료한다. [Valve 심사 기준](https://partner.steamgames.com/doc/store/review_process)은
스토어에 적은 출시 기능과 실제 빌드의 일치, 실행 가능한 제품과 실제 게임
화면을 요구한다. 최종 가격·출시일·공개 결정은 사용자가 준비된 뒤 정한다.

[콘텐츠 설문 초안](content-survey-draft.md)과 [변경 내역](changelog.md)을 함께
제공한다. 설문은 개발 중 AI 도구로 만든 플레이어용 미술/음악과 실행 중 AI
모델 생성 여부도 확인한다. 현재 초안은 실제 설문 제출이나 등급 승인 결과가 아니다.
