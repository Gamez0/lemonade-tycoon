# M2 목표 자체 검토

2026-09-29. 도로·날씨·영업 화면 보완(PR #102)을 먼저 완료하고, 사용자 요청에 따라 별도 검토를 수행했다. 검토 기준은 `m2-original-study.md` 8절이며, 단순히 구현 항목 수나 CI 통과로 합격시키지 않는다.

## 판정

**아직 M2 완료라고 선언하지 않는다.** 기능 검증과 화면 구조는 목표를 충족하는 방향이지만, 이번 재검토에서도 정보 누락 두 건과 원작 조작 누락 한 건을 찾았다. 이를 보완하고 다시 검증한다. 최종 시각 승인은 #97에 남겨둔다.

## 이번 검토에서 찾은 문제와 조치

1. **521~700px에서 뉴스와 하루 진행 정보가 사라짐.** 기존 미디어 쿼리가 전체 영역을 숨겼다. 예보의 양쪽 정보가 남도록 수정하고 375/520/640/768px에서 보이는지 검사한다.
2. **375/520px 재료 탭에서 Start day가 약 22px 내려감.** 재료 목록이 패널 최소 높이를 넘었다. 다른 준비 탭과 같은 행동 위치를 확보하고 네 탭의 실제 버튼 좌표를 비교한다. 오류 메시지 때문에 필요한 확장은 허용한다.
3. **원작에 보이는 SKIP 조작이 없었음.** 준비 경제나 대기열을 추가하지 않고도 M2에서 보완할 수 있는 조작이다. 이미 처리된 손님 이후의 현재 상태부터 남은 방문을 계산하고 결과로 넘어간다. 진행 중 애니메이션을 정리하므로 일반 종료의 마지막 퇴장 대기와 구분한다. 즉시 건너뛰기/한 명 이상 처리 후 건너뛰기를 정상 하루 계산과 대조한다.
4. **저장 한도 초과의 브라우저 경로가 빠져 있었음.** 앞 재료의 구매가 가능해도 뒤 재료가 저장 한도를 넘으면 모든 구매가 취소되어야 한다. 얼음 900 보유 후 레몬 40+얼음 120 주문으로 확인한다. 원상태·잔액·초안 보존까지 검사한다.

## 남은 차이를 숨기지 않음

- **시각 승인 필요:** 제목 글꼴은 원작 폰트가 아니며 아이콘·집·나무는 새로 만든 그림이다. 구조/비율/조작을 가깝게 했어도 원작 특유의 질감까지 동일하다고 단정할 수 없다. 비교 보드로 사용자가 판단할 수 있게 남긴다.
- **모션 근거 부족:** 두 번째 롱플레이도 페이지는 열렸지만 180초 탐색에서 readyState 1로 멈췄다. 연속 장면 관찰에 성공한 것이 아니다. 보행 속도·회전·음용 타이밍의 정확한 재현은 주장하지 않는다.
- **명시적인 규칙 차이:** 현재 날씨는 하루 동안 고정이다. 실제로 계산하지 않는 시간별 기온 범위나 변화를 예보에 그려 넣지 않는다. 피처 생산, 녹는 얼음, 임대·광고·직원 비용도 현재 컵 단위 경제에 섞지 않는다.
- **M3 범위:** 동시 보행/방문, 줄 서기, 서비스 용량, 오래 기다려 떠남은 사용자 지시에 따라 milestone 3 / #100에 둔다. 단일 손님 처리를 이 기능의 완료로 간주하지 않는다.
- **후속 범위:** 저장/불러오기, 추가 장소와 경제 확장은 별도 로드맵에 남아 있다.

## 확인 방법

M2의 반려 항목을 문서로만 넘기지 않고 수정한다. 자동 검증 후 원작과 나란히 보는 보드를 다시 확인한다. 특히 영업 화면의 속도/SKIP, 현재 날씨, 실적/설정, 마지막 고객과 결과 화면 전환을 직접 본다. 자동 검증 통과는 기능 근거이며 시각 승인 자체는 아니다.
