# M3 거리·대기열 관찰과 구현 계약

2026-09-30. [원작 PC판 롱플레이](https://www.youtube.com/watch?v=IdnO6ntYAgs&t=620s)의 10:21–10:32 구간을 재생해 연속 장면을 확인했다. 이 영상은 R01–R10의 Windows 1.1.5 스크린샷과 탭 구성이 다른 판본이다. 관찰한 거리 동작을 참고하되 수치나 메뉴 구성은 판본 사이에 옮겨 적지 않는다.

## 영상에서 직접 본 것

- 영업 전환 뒤 장면 안에 서로 다른 방향으로 걷는 보행자가 여러 명 동시에 보인다. 약 10:26에는 가판대 앞에 두 사람이 붙어 있고, 다른 사람이 보도를 지나간다.
- 10:28–10:30에는 가판대 앞·길 건너편·도로 아래쪽에서 움직이는 사람들이 동시에 보인다. 인물은 가판대와 집, 도로에 가려지는 순서가 다르다.
- 가판대 주변과 보행자 위에 반응 말풍선이 나타나며, 좌측의 컵 판매 수·수익·반응 수치와 상단 재고/현금이 영업 중 바뀐다.
- 이 짧은 구간만으로 정확한 손님 도착 간격, 인내심, 서비스 시간, 줄 용량, 개인별 구매 판정 시점은 측정할 수 없다. 영상 프레임만으로 기다리다 떠난 사람과 단순 통행인을 항상 구분할 수도 없다.

[원작 설명 자료](https://addictgaming.com/games/lemonade-tycoon)는 긴 줄과 재고 문제, 대기 시간·인내심에 영향을 주는 설비/직원을 언급한다. 이는 대기열이 경영 규칙이라는 보조 근거지만 정확한 수치는 제공하지 않는다.

## M3에서 정할 규칙

아래 수치는 **우리 게임의 결정적 규칙**이며 원작 측정값이 아니다. 시뮬레이션의 고정 시간 틱으로 처리해 프레임 속도·배속·SKIP에 따른 회계 차이를 없앤다.

기본값은 1틱=100ms, 도착 간격 5틱, 서비스 8틱, 줄에서 기다리는 한계 18틱, 통행·퇴장 표시 22틱이다. 한 명만 서비스를 받으며 별도 인원/설비 효과는 M6에서 추가한다.

1. 하루의 `weather.traffic`은 거리로 들어오는 사람 수다. 각 사람은 고유 ID와 생성 당시 정해진 프로필/의도를 가진다. 통행인과 가격 거절은 재고를 쓰지 않고 지나간다.
2. 구매 의도가 있는 사람은 줄 끝으로 들어간다. 한 번에 한 사람만 서비스를 받는다. 서비스를 마칠 때 재고를 검사하고 결제/재료 차감을 한 번만 확정한다.
3. 줄에서 기다리는 시간이 한계를 넘으면 대기 포기로 처리하고 놓친 판매에 기록한다. 서비스 중인 사람은 기다림 제한을 적용하지 않는다. 재고 부족은 대기 포기와 별도 사유다.
4. 진행 순서는 **도착 → 인내심 검사 → 서비스 완료/시작 → 종료 판정**으로 고정한다. 영업 종료는 모든 예정 도착과 줄/서비스 결정이 끝난 뒤다. 화면의 퇴장 애니메이션은 회계 완료를 다시 실행하지 않는다.
5. SKIP은 같은 틱 규칙을 끝까지 실행한다. 이미 결제된 사람을 다시 처리하지 않고, 처리 중이던 줄/서비스와 아직 오지 않은 사람을 포함한다. 재시작/다음 날에는 모든 거리 개체를 제거한다.

완료 검증은 여러 개체 동시 표시, 겹치지 않는 대기 위치, 독립된 입장·대기·서비스·퇴장, 정상/4배속/SKIP의 동일한 최종 상태, 마지막 손님·품절·무판매·대기 포기·다음 날·재시작을 포함한다. 장부에는 통행/가격 거절/품절/대기 포기를 구분하고 하루의 모든 도착을 정확히 한 번만 합산한다.

기존 이슈 [#16](https://github.com/Gamez0/lemonade-tycoon/issues/16)은 구매/이탈을 결정할 때 손님이 가판대를 향해 서는 동작을 요구한다. M3에서는 줄에 서거나 서비스를 받을 때 인물 얼굴이 가판대 쪽(왼쪽)으로 향하게 하고, 길로 나갈 때 다시 진행 방향으로 향하게 한다. 원래 이슈의 레거시 Tiled 경로 변경과는 구현 방법이 다르므로 시각 확인 전에는 #16을 닫지 않는다.

## 구현 화면 점검

[현재 M3 영업 캡처](m3-queue.png)는 가격 $0.25와 초기 재료 각 한 묶음으로 영업을 연 뒤 찍었다. 세 인물이 가판대·도로·오른쪽 보도에 서로 다른 위치로 나타나고, 상단 재고와 좌측 판매 수가 거래에 맞춰 갱신된다. 이 장면은 원작 영상의 인물 크기·포즈·말풍선 위치와 계속 비교할 대상이며, 원본 프레임을 에셋으로 사용하지 않았다.
