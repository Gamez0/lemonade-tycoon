# 영업 화면과 날씨 후속 조사

2026-09-29. 사용자 요청: M2에서 원작과의 전반적인 시각 차이를 더 꼼꼼히 줄인다. 동시 보행, 대기열, 긴 대기로 인한 이탈은 M3로 분리한다.

## 직접 다시 확인한 화면

- [R08 공원 영업](https://games-cdn.softpedia.com/screenshots/Lemonade-Tycoon_8.jpg): 영업 중 UI 기준. Performance와 Today's Settings, Current Weather, 장면 안 오른쪽 아래의 배속/건너뛰기.
- [R11 주택가 영업](https://www.mobygames.com/game/44300/lemonade-tycoon/screenshots/windows/854921/): 다른 언어/탭 구성의 보조 자료. 날씨 그림+기온, 구분선으로 정리한 설정, 그림으로 표시한 레시피를 교차 확인.
- [R06 준비](https://games-cdn.softpedia.com/screenshots/Lemonade-Tycoon_6.jpg): 날짜 밑 기온 범위와 시계/날씨 그림이 있는 예보. 영업 화면의 현재 날씨와 표현이 다름.
- [R09 결과](https://games-cdn.softpedia.com/screenshots/Lemonade-Tycoon_9.jpg): 작은 장부와 고객 피드백을 나란히 배치. 일일/기간별 결과는 그림 탭으로 구분.

영상의 연속 재생은 여전히 검증되지 않았다. 위 화면으로 확인할 수 있는 배치와 상태 차이만 근거로 삼는다. 대기열/이탈은 사용자가 제공한 원작 경험이자 M3 요구사항으로 기록하며, 이번 조사에서 관측한 수치로 취급하지 않는다.

## M2에서 발견한 차이와 수정 방향

| 영역 | 기존 M2의 차이 | 이번 수정 |
| --- | --- | --- |
| 날씨 | Sunny / 32°C라는 한 줄 텍스트. 준비와 영업이 똑같음 | 원작처럼 날짜, 날씨 그림/기온, 뉴스 분리. 준비는 Forecast, 영업은 Current weather. 현재 규칙은 하루 동안 고정 기온이므로 가짜 최저/최고 기온이나 시간별 예보를 만들지 않음 |
| 영업 실적 | 웹 표처럼 금액과 긴 문장 위주 | 가는 구분선, 실적 수치, 그림과 숫자의 고객 반응, 짧은 현재 소식 |
| 오늘 설정 | 가격/레시피/재고를 줄바꿈한 문자열 | 장소/임대/가격/컵당 레시피/남은 판매량을 구분된 행으로 구성. 레시피는 재료 그림과 수치 사용 |
| 속도 | 장소 설명 아래의 독립 버튼 | 원작처럼 장면 안 오른쪽 아래. 속도 아이콘과 배수. 후속 목표 재검토에서 SKIP도 구현. 일반 종료는 마지막 손님 퇴장 대기, SKIP은 현재 상태부터 남은 방문을 즉시 계산 |
| 장소 평가 | 큰 상태 줄, 진행 막대, 피드백으로 길어짐 | 장소 설명 아래 평판/구매자 만족도를 나란히 배치. 영업 진행 정보는 날씨/실적 쪽으로 이동 |
| 글자와 여백 | 동일 표시 폭에서 제목·본문이 원작보다 작고, 남는 녹색 공간이 큼 | 제목·수치·본문 계층을 키우고 패널 높이/여백 재조정. 원작의 세로로 긴 제목 느낌 유지 |
| 레시피/재료 | 길쭉한 웹 입력 행과 작은 더하기 버튼 | 더 큰 재료 그림, 방향성이 있는 화살표 조작, 작고 촘촘한 묶음 행 |
| 결과 | 모든 정보가 하나의 긴 표 | 금액 장부와 해석/고객 평가를 구분하고 실제 동작하는 보고서 탭에 그림 추가 |
| 도로 | 샛길 차도가 큰길 보도 앞에서 끊김 | 같은 투영의 연속 T자 도로/보도, 합류부 차선 정리, 보행 경로의 횡단 표시 |

현재 모델에 없는 광고비·직원·업그레이드·인기 수치를 장식용으로 채우지 않는다. 실제 값과 원작에서 빌린 표현 형식을 구분한다. 컵당 레시피와 기존 경제 규칙은 유지한다.

## 검수

준비/영업/결과별 화면을 다시 캡처하여 원작과 같은 폭으로 비교한다. 맑음/흐림/비 상태, 영업 시작 시 문구와 편집 잠금, 위치가 고정된 장면, 배속과 마지막 고객 퇴장, 결과/다음 날 전환 및 375px 조작을 확인한다. M2의 사용자 시각 승인은 아직 남아 있다.
