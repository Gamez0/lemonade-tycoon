# Neighborhood raster study assets

Created 2026-10-20 KST with the built-in OpenAI image-generation tool.

The house/hedge structural references were generated by this repository's own
study scripts. The painted house then supplied a style reference for the cottage
and tree; the generated tree supplied the hedge's foliage reference. No original
Lemonade Tycoon screenshot, decoded asset or binary was supplied to generation.

Each PNG is retained unmodified, including its alpha channel. The corresponding
`.prompt.txt` is the exact submitted prompt. These are generated candidates,
not evidence of user visual acceptance or exact historical-game fidelity.

| Candidate | Role | Product asset |

| left-house-painted-v1.png | First material study; rejected for perspective drift | Not shipped |
| left-house-painted-v2.png | Orthographic correction of v1 | src/game/assets/neighborhood-house-left.png |

| garden-hedge-v1.png | Diagonal low clipped hedge | src/game/assets/neighborhood-hedge.png |

Reproduce the structural studies and local review boards from the repository root:

```powershell
node scripts/art-studies/house-structure.cjs
node scripts/art-studies/blockout-board.cjs
node scripts/art-studies/raster-review.cjs v2
node scripts/art-studies/painted-context.cjs
```

Outputs are private, ignored `.local-m4/house-structure/` artifacts. The blockout
script reads the pre-redesign code at56ddb48 for its comparison background and
sprite textures. The painted-context script uses the actual candidate renderer,
so its house/prop placement cannot silently diverge from the game.

Production crops/anchors are in `src/game/presentation/painted-neighborhood.ts`.
The high-resolution images are averaged once onto the 300x240 map grid, then the
finished map is enlarged with nearest-neighbor sampling. They are not vector
placeholders or source-game extractions. Final visual acceptance remains #97.
