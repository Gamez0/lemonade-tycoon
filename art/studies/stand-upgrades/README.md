# Independent upgradeable stands — 2026-10-20

Four separate alpha PNGs generated with the built-in OpenAI image tool from our
own map style study and own prior procedural cart; Classic then supplied the
structure/style reference for Lemon and Castle. No original-game image was input.
Each exact submitted prompt and unmodified output is retained here.

Selected outputs are copied to `src/game/assets/stand-{basic,classic,lemon,castle}.png`.
`presentation/stand-art.ts` records alpha crop bounds and renders each once onto
the logical grid. The Phaser scene overlays one selected texture at a shared
bottom-center ground anchor. Neither the map nor rent thumbnail includes it.
Upgrading changes only the saved stand tier and selected sprite, not map assets.

Basic/Classic/Lemon/Castle names and upgrade purchase prices449.99/999.99/9999.99
were observed in the original equipment UI; see research/original-116-live-audit.md.
No unverified storage-capacity, attraction or speed effect is assigned here.
Source illustration quality and historical-game art equivalence remain human
acceptance items. The current visible stage is also exposed in the canvas label
attributes for accessibility and automated evidence.
